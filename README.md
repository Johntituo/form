# FORM 公共健身规划网页

这是一个可以部署成公共网址的响应式健身规划网站。访客可在电脑、平板和手机上打开；个人参数、训练打卡与历史记录保存在各自的浏览器中。开发者登录后可修改公共标题、公告和全站训练模板。

## 当前实现内容

- 响应式布局：桌面侧栏、手机底部导航。
- 参数驱动计划：体重、每周训练天数、训练场景、可用器材、单次时长、经验与有氧偏好都会影响计划内容或能量估算。
- 训练安排、动作完成打卡、训练记录、体重记录、个人 JSON 备份。
- 根据每个动作的 MET、估算分钟数、用户体重计算运动能量；这只是估算，不是实测值。
- 动作教学库、要点提示、YouTube 教学嵌入播放器（需要可访问相关视频平台的网络）。
- 开发者选项：服务端密码验证；支持编辑品牌、首页副标题、公告和全站训练模板。保存后对全部访客生效。
- 登入限速、HttpOnly 会话 Cookie、SameSite Cookie、服务器端配置校验、YouTube 域名白名单。
- 数据不依赖任何浏览器扩展。

## 重要：公共网址与开发者密码

不要把网页做成纯静态网页再把密码写到 JS 里。纯静态的前端密码可以被访客查看源码。本项目使用 Node.js 服务端验证密码，`ADMIN_PASSWORD` 不会发送到浏览器。

服务器必须设置两个环境变量：
- `ADMIN_PASSWORD`：你自己的强密码，至少 12 个字符。建议使用独特且不可猜的密码。
- `SESSION_SECRET`：至少 32 个字符的随机字符串。
- `DATA_DIR`（可选）：网站公共配置的持久化目录。部署到挂载了持久磁盘的平台时应指向该路径。

不要把真正密码写进源码、README 或提交到 Git。

## 在 Windows 上本地运行

1. 安装 Node.js 20 或更新版本。
2. 把此文件夹放在你希望的位置，例如 `D:\FORM-Public-Fitness`。
3. 在此目录复制 `.env.example` 并命名为 `.env`。
4. 用文本编辑器打开 `.env`，设置自己的 `ADMIN_PASSWORD` 和随机的 `SESSION_SECRET`。
5. 在此目录打开 PowerShell 或终端，运行：
   ```powershell
   npm install
   npm start
   ```
6. 浏览器打开 `http://localhost:8765`。同一 Wi-Fi 下的手机若要访问本机开发服务器，需要查看电脑局域网 IP，并确保防火墙允许访问；这不是公共互联网网址。

## 部署成公共网址（推荐 Render）

这需要你自己登录托管平台并连接代码仓库；此对话无法代替你登录、创建项目或直接替你发布到账号。

1. 将本项目上传到自己的 GitHub **私有仓库**（更不容易暴露未来的运营代码）。确保 `.env` 没有提交。
2. 在 Render 选择 New → Web Service，连接仓库。
3. Runtime 选择 Node；Build Command 填 `npm install`；Start Command 填 `npm start`。
4. 在服务的 Environment 中添加：
   - `ADMIN_PASSWORD` = 你的强密码（至少 12 位）
   - `SESSION_SECRET` = 随机生成的长密钥（至少 32 字符）
   - `NODE_ENV` = `production`
   - `DATA_DIR` = `/var/data`
5. **添加持久磁盘**并将挂载路径设为 `/var/data`。当前服务把开发者所做的全站内容修改保存在 `DATA_DIR/site.json`。没有持久存储的临时文件系统会在重启或重新部署时丢失改动。Render 官方文档说明持久磁盘目前需要付费 Web Service：<https://render.com/docs/disks>。
6. 部署完成后，平台会给你一个 `*.onrender.com` 公共 URL，手机和电脑都能访问。可以之后配置自有域名。

如果不想使用 Render，也可部署到你自己的 VPS / 云服务器；保证 Node 服务持续运行、HTTPS 已启用，并让 `DATA_DIR` 指向持久目录即可。

## 第一次打开网页时

- 点左侧（手机为顶部）“开发者选项”。
- 输入部署时设置在 `ADMIN_PASSWORD` 中的密码。
- 基础内容可直接修改；训练动作与模板配置使用 JSON 编辑器。
- 点击“保存公共网页配置”，服务端校验并保存，访客刷新后看到新内容。
- 可先点“导出配置”备份 JSON。修改动作视频时，使用 YouTube 链接；服务端只接受 HTTPS YouTube 地址。

## 数据与边界

- 访客的身体信息、打卡与训练记录使用 `localStorage` 保存。它们不会自动同步到其他设备或账号；可用“导出个人数据”备份。清理浏览器数据会移除该设备上的个人记录。
- 开发者所修改的公共页面配置保存在服务端 `site.json`，与个人训练记录分开。
- 当前开发者登录会话保存在单实例内存中，服务重启后需要重新登录。这不会删除公共页面配置。
- 教学视频嵌入依赖外部 YouTube 与网络连通性；部分视频可能关闭嵌入，暂时没有视频的动作仍提供文字要点。你可以在开发者配置中换成允许嵌入的链接。
- MET 是估算强度值。实际能量消耗取决于动作执行时间、间歇、体能、运动效率与设备等因素；不要把估算当作准确测量。
- 计划是通用模板，不是医疗建议。出现疼痛、眩晕或异常不适时停止训练。

## 常见问题

**开发者选项提示未配置？** 检查服务器环境变量是否设置并重新部署。密码不在浏览器中设置。

**保存后其他访客看不到更新？** 确认已登录成功、服务端 `/api/admin/site` 返回成功，以及数据目录具有写入权限并在持久磁盘内。

**网页能打开，但视频不播放？** 检查网络是否可以访问 YouTube，或该视频是否允许嵌入。替换 `videoUrl` 即可更换教学视频。

**如何重置公共默认模板？** 用开发者选项载入备份的配置 JSON；若要回到初始模板，可用 `data/site.seed.json` 的内容导入。
